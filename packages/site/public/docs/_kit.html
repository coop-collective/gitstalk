Quickstart steps with copyable code

  1. Create a branch

    Beans are branches named bean/<name>.

    Terminal
    git switch -c work origin/sprout

  2. Push it

    Terminal
    git push -o wait origin HEAD:refs/heads/bean/add-truncate

  3. Read the verdict

    Output without a prompt uses pre class="url".

    Output
    remote: gitstalk: LANDED: add-truncate is on the sprout

Tabbed code

Claude Code: paste in your terminal
/gitstalk:setup <owner>/<repo>
Codex: paste in your terminal
codex mcp login gitstalk
Plain git
git remote add gitstalk git@gitstalk.dev:<owner>/<repo>.git
