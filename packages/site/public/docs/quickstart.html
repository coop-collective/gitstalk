Quickstart: your first bean in a minute

Six short steps from nothing to a change landed on your own repository. Each step shows what the screen looks like.

live Everything on this page works on the hosted service today.

  1. Sign up

    Open Sign up. Create the account with a passkey and a handle, or continue with an email address and the six-digit code we send (it works for 10 minutes). A new email address then asks for a handle.

  2. Create a repository

    Choose New repository from Home. The TypeScript starter has a test every bean must pass, so your first push is checked for real.

  3. Connect your agent and git

    Install the plugin in Claude Code or Codex. Your browser opens once to approve the session.

    Claude Code: paste in your terminal
    claude plugin marketplace add coop-collective/gitstalk-plugin && claude plugin install gitstalk@gitstalk && claude mcp login plugin:gitstalk:gitstalk
    Codex: paste in your terminal
    codex plugin marketplace add coop-collective/gitstalk-plugin && codex plugin add gitstalk@gitstalk && codex mcp login gitstalk
    Any MCP client: add as a remote (HTTP) server
    https://mcp.gitstalk.io/mcp

    Then connect git on this machine. In Claude Code:

    Claude Code
    /gitstalk:setup <owner>/<repo>

    It finds your SSH keys or makes one, opens a Gitstalk tab for you to approve it, then clones the repository or points your clone at it. In Codex, ask it to run the setup script (setup.sh, or setup.ps1 on Windows).

    Git runs over HTTPS today

    Git over SSH is built but not public yet. Setup still registers your key (that approves the machine), and because the SSH remote is not public it stores an HTTPS token in git's credential helper and sets an HTTPS remote. Never paste that token into a chat or a remote URL.

  4. Push a bean

    A bean is a branch named bean/<name>. Start from the sprout, change something, and push with -o wait to hold the push until the verdict.

    Terminal
    git switch -c work origin/sprout
git commit -am "Add a truncate helper"
git push -o wait origin HEAD:refs/heads/bean/add-truncate

    The stalk moves a little later, when CI validates the sprout. The bean's status ref then gets the line gitstalk: validated: on the stalk at <sha>, and the History tab moves the commit from On the sprout, not validated yet to The stalk.

  5. See it in the app

    Open the repository and its Changes tab. It lists beans in three groups, Open, Landed and Parked, and the page updates live.

  6. Ask your agent to do it

    The plugin teaches your agent this flow, so you can skip the commands. Try:

    Chat
    Add a truncate helper to ada/notes-api with a test. Push it as a bean and tell me whether it landed.

    If a bean goes red, the push tells the agent which tests failed and which landed beans it collided with. See Concepts.

What you will see on Home

Invitations to other people's repositories appear on Home with the answer buttons. Connected agents show under Your sessions, newest first; each can be disconnected in Settings.
